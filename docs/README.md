# 文档索引

改一个模块之前，先读它的文档。决定和约束记在这些文档里，Issue 和 PR 评论只作参考，两者不一致时以文档为准。新增文档时在这里加一行。

- [mcp.md](mcp.md)：对外的 MCP 契约：端点和协议、对象、9 个工具和 2 个 prompt、续页和日期规则、错误、新鲜度、返回内容的安全处理、层级与限额、计量口径、版本规则。工具表、prompt 和兼容清单与 schema 的一致性由 `npm run check:contract` 检查。
- [design.md](design.md)：代码规范（运行时、契约定义、工具说明里的引导句、测试、转发程序的不变量）和设计决定：工具定义以本仓库为准；契约文档拆成公开和内部两份；TypeScript 写定义、提交生成的 JSON；开发用 Node 24、用户侧支持 Node 20；安全样例共享发包；agent 使用评测等服务端上线后再做。以及还没定的事。
